The current developer preview, and what it includes.

0.4.17 · Developer preview

Your latest Cue Mac update.

The latest public download includes the chat sidebar, message controls, and answer reliability improvements.

  • A collapsible, searchable sidebar for Chats, Recordings, and Trash, with pin, rename, and restore controls.
  • Copy and edit sent messages on hover, with expandable previews that preserve code spacing.
  • Saved conversations with optional bounded context, isolated preferences, and compact recent-chat memory.
  • A Stop control, request deadlines, audio buffering, and recovery that restores saved chats after an interrupted answer.
  • Meeting-mode instructions up to 64,000 characters, plus a choice of this desktop or all desktops.
  • Apple silicon and Intel downloads include the local Whisper runtime; speech models download separately.

This update is signed with the existing local development certificate. It is not Apple Developer ID signed or Apple-notarized. Read the installation guide.
