# Cue 0.4.15

The live-call header shows independent **You** microphone and **Call** system-audio
meters. Both use the existing PCM capture pipeline, with different waveform/bar
shapes, a quiet noise floor, reduced-motion support, and accurate muted,
unavailable, paused, and stopped states. No additional capture or model request
is introduced. The indicators reuse the transcription header so a minimum-size
overlay retains room for answers and multiline input. Late transcript events
cannot relight the listening dot after capture stops.

Response context now prioritizes the latest spoken question and its preceding
conversation, distinguishes unfinished speech and generated drafts, and retains
a bounded memory-only thread for typed follow-ups. **New thread** preserves the
transcript while clearing answer context. Failed or stale generations cannot
repopulate a cleared thread. Details are in [audio activity](../audio-activity.md)
and [response generation](../response-generation.md).

Regression coverage includes synthetic microphone and loopback audio through
AudioWorklets and the legacy fallback, independent silence and mute/recovery,
meeting-audio opt-out, permission rejection, a missing microphone, session
stop/restart, final transcript preservation, response context, and compact
live-call layout. The tests use temporary profiles and no physical inputs or
provider accounts.

Downloads remain the explicitly approved, locally certificate-signed developer
preview, without Apple Developer ID signing or notarization. Public artifacts
are built from the committed source for Apple silicon and Intel; exact byte
counts and SHA-256 hashes are published in the website release manifest. Local
settings, provider credentials, models, sessions, private signing material, and
rollback archives are excluded.
