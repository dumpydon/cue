# Cue 0.4.0 checkpoint

This checkpoint preserves the local application refinements before further work on macOS capture permissions.

## Included

- Cue branding and monochrome menu-bar assets.
- Dragging on non-interactive surfaces, eight resize directions, and an icon-only resize grip.
- Fixed window bounds during content zoom.
- Partial off-screen parking at the left, right, bottom, and bottom corners, with position restoration.
- Screen-share protection toggle, native tray actions, and local session history.
- Compatibility fixes for OpenAI model request parameters.
- Editable Fast/Smart model pickers, provider-scoped history, deletion, and compatible-model discovery.
- Meeting modes with editable titles and contexts, automatic saving, activation, reordering, duplication, deletion, and undo.
- Per-mode PDF, DOCX, TXT, and Markdown references, included only with the active mode in user-facing AI requests.
- Interview, Behavioral Interview, Coding Interview, System Design, Case Interview, and additional meeting presets.
- Atomic local settings persistence with backup recovery and restricted file permissions.

## Validation

The checkpoint passed 371 unit tests and the Electron interaction suites in:

- `scripts/smoke-window.cjs`
- `scripts/smoke-refinement.cjs`
- `scripts/smoke-model-picker.cjs`
- `scripts/smoke-meeting-modes.cjs`

The interaction suites use isolated profiles and synthetic provider responses; they do not use private keys, real meeting data, or desktop/audio capture. Native macOS checks were performed separately.

## Known issue under investigation

macOS can show Screen Recording enabled in System Settings while the installed app reports capture access unavailable. The local build uses an ad-hoc signature whose designated requirement is tied to its code hash, so replacing or re-signing the bundle can invalidate the previous grant. Duplicate registrations and permission-status behavior also need to be checked before declaring this resolved.

No API keys, local settings, personal reference files, meeting recordings, transcripts, build caches, or installed-app backups are part of this checkpoint. Developer ID signing and notarization remain requirements for a distributable macOS release.
