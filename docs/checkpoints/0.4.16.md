# Cue 0.4.16

- Local chat threads persist across restart, with automatic titles, rename,
  search, continue, and recoverable Trash for chats and recordings.
- Per-chat instructions and explicit preferences can be viewed, edited or
  forgotten. Newer preferences supersede old ones; automatic memories expire
  after 90 days. No paid memory, title or summarization calls are added.
- Prior context is capped at 90% of the fresh estimated text input and 1,800
  added tokens. This bounds history growth; it is not a guaranteed dollar-cost
  multiplier across providers, outputs, reasoning or cache pricing.
- Partial answers checkpoint locally and restore as interrupted, excluded from
  future inference context. Existing recordings remain available.
- Sent prompts preserve whitespace, support six-line expand/collapse, text
  selection, full-message copy and native selected-text copy.

Validated with 430 unit tests, two-process restart and 50-problem budget tests,
plus answer formatting, prompt selection/copy, response context, live-audio and
window interaction suites. Public archives are clean source builds for Apple
silicon and Intel, using the existing local signing identity and bundled
whisper.cpp runtime. This remains a non-notarized developer preview.
