# Toolbar icon assets

Created with the built-in imagegen tool in generation mode with transparent backgrounds. PNG alpha masks follow the toolbar’s text color. Opacity uses overlapping glass panes. The pin tilts right: head upper-right, needle lower-left. The stacked-desktops symbol identifies the all-desktops state.

Saved assets:
- `renderer/assets/toolbar-opacity-v2.png`
- `renderer/assets/toolbar-pin-v2.png`

Earlier assets are retained as previous versions and are no longer referenced by the toolbar.

## Final prompts

### opacity

Use case: logo-brand. Asset: one polished macOS app toolbar icon, final display size 18 pixels. A transparency icon made of exactly TWO overlapping rounded square glass panes. Back square offset slightly upper-left; front square offset lower-right, overlapping halfway. Thin crisp outlines for both. The back pane has NO fill. The front pane has a subtle flat black fill at 22% alpha, and the intersection at 45% alpha so the overlap communicates transparency, while all outlines are opaque black. The back outline remains visible through the front pane. Simple geometrically aligned rounded squares, no internal checkerboard, no solid opaque blocks. No circles, no moons, no tiny dots or sparkles. Genuinely transparent background. Monochrome BLACK marks only. Crisp smooth vector-like geometry, consistent monoline stroke about 7% of icon width, rounded caps and joins. Centered square canvas, tight about 9% clear margin around the glyph. Must read immediately at tiny size and match a professional thin outline toolbar icon family. No text, no labels, no surrounding container, no texture, no roughness, no speckles, no shadows, no 3D, no gradients. Preserve fully transparent hollow regions.

### pin

Use case: logo-brand. Asset: one polished macOS app toolbar icon, final display size 18 pixels. A single elegant pushpin tilted RIGHT by 35 degrees clockwise: its rounded cap/head is in the UPPER RIGHT and its sharp needle points LOWER LEFT. It is unmistakably diagonal, never upright. Compact clean proportions: small capsule cap, short narrow neck, gently flared curved shoulders, one straight needle. Thin hollow outline, balanced generous interior negative space. A simple familiar pin symbol like a refined modern interface icon, not a decorative drawing. Genuinely transparent background. Monochrome BLACK marks only. Crisp smooth vector-like geometry, consistent monoline stroke about 7% of icon width, rounded caps and joins. Centered square canvas, tight about 9% clear margin around the glyph. Must read immediately at tiny size and match a professional thin outline toolbar icon family. No text, no labels, no surrounding container, no texture, no roughness, no speckles, no shadows, no 3D, no gradients. Preserve fully transparent hollow regions.
